# Data requirements

The repository does not include raw charging-order records or proprietary intermediate files. To run the code, users need to provide the following input files under `data/`.

## 1. `charging_sessions.csv`

Used by `code/01_tou_tariff_rules.py`.

Required variables:

| Variable | Description |
|---|---|
| `id` | Charging-session identifier |
| `province` | Province name in English, matching `NATIONAL_TOU_RATES` |
| `city` | City name in English for provinces with regional rules |
| `begin_time` | Charging start timestamp |
| `deep_valley_rate` | Electricity price during deep-valley periods, if applicable |
| `super_peak_rate` | Electricity price during super-peak periods |
| `peak_rate` | Electricity price during peak periods |
| `shoulder_rate` | Electricity price during shoulder periods |
| `valley_rate` | Electricity price during valley periods |

## 2. Optional `tou_rules.json`

Used by `code/01_tou_tariff_rules.py`.

The script already embeds the public provincial TOU tariff schedules used in
the paper. Users only need to provide `tou_rules.json` if they want to override
or update the embedded rules. The embedded rules use English province and city
names, such as `Beijing`, `Shandong`, `Hebei`, `Shijiazhuang`, and `Hohhot`.

Expected schema:

```json
{
  "ProvinceName": {
    "versions": [
      {
        "start_ym": "2023-01",
        "end_ym": "2024-12",
        "periods": {
          "summer": {
            "months": [7, 8],
            "time_slots": {
              "valley": ["00:00-07:00", "23:00-24:00"],
              "shoulder": ["07:00-10:00"],
              "peak": ["10:00-23:00"]
            }
          }
        }
      }
    ]
  }
}
```

Allowed period names are `deep_valley`, `super_peak`, `peak`, `shoulder`, and `valley`.

## 3. `transition_panel.csv`

Used by `code/02_rdd_price_transitions.do`.

Required variables:

| Variable | Description |
|---|---|
| `total_kwh_per_minute` | Charging load per station-minute |
| `relative_minute` | Minute relative to the tariff transition cutoff |
| `transition_type` | `1` for high-to-low transitions, `2` for low-to-high transitions |
| `date` or `date_id` | Calendar date |
| `station_name` or `station_id` | Charging station identifier |

## 4. `charging_choice_panel.dta`

Used by `code/03_elasticity_ols_ppml.do`.

Required variables:

| Variable | Description |
|---|---|
| `id` | Charging session identifier |
| `choice` | Indicator equal to one for the realized charging-time alternative |
| `alt_index` | Half-hour alternative index |
| `expected_price` | Expected electricity price for the alternative |
| `ele_amount` | Observed charging electricity consumption |
| `begin_soc` | Initial state of charge |
| `is_fast_charge` | Fast-charging indicator |
| `province` or `province_id` | Province identifier |
| `station_name` or `station_id` | Charging station identifier |
| `zone_type` or `zone_id` | Station land-use or functional-zone category |
| `temperature` or `temp_bin` | Weather control |
| `date` or `date_id` | Calendar date |

## 5. `renewable_hourly_profiles.csv`

Used by `code/05_grid_renewable_emissions.do`.

Required variables:

| Variable | Description |
|---|---|
| `province` | Province identifier |
| `hour` | Hour of day, 0--23 |
| `renewable_cf` | Composite wind-solar capacity factor |
| `wind_cf` | Wind capacity factor |
| `solar_cf` | Solar capacity factor |

## 6. `hourly_emission_factors.csv`

Used by `code/05_grid_renewable_emissions.do`.

Required variables:

| Variable | Description |
|---|---|
| `province` | Province identifier |
| `hour` | Hour of day, 0--23 |
| `emission_factor_kg_per_kwh` | Hourly grid emission factor |
